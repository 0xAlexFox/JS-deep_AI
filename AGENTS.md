# Локальные служебные файлы

- Храни логи тестов, сборок, временных серверов и другие служебные результаты в `.local/`.
- Перед записью создай папку при необходимости. Не создавай служебные `*.local` в корне проекта.
- Исключение: `.env.local` с настоящим ключом остаётся в корне; публичный образец — `.env.example` рядом с ним.
- Не публикуй `.local/` и не выводи секреты в консоль. Папка исключена из Git и закрыта для HTTP-доступа.
- Не удаляй прежние результаты проверок при наведении порядка; сохраняй их имена и содержимое.
